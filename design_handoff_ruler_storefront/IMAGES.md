# Image manifest

All product photography in the prototype is hotlinked from free-licence CDNs
(Unsplash Licence / Pexels Licence — commercial use, no attribution required).

**Before production:** download each file, run it through an image pipeline
(AVIF + WebP, 400/800/1600 widths), and serve from your own origin or CDN.
Do not ship hotlinks. Replace with real product photography when available:
one background, one light direction, one camera height across the catalog.

Shot list the layout expects, per product:
1. Hero / packshot — 4:3, product filling ~70% of frame, neutral background
2. Detail — macro of the graduations or edge, 1:1
3. In-hand / in-use — 1:1
4. Scale reference — 1:1, product next to a known object
5. Packaging / case — 1:1
